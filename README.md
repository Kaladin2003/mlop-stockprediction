# MLOps για την Πρόβλεψη Μετοχών του S&P 500 σε Πραγματικό Χρόνο

Διπλωματική εργασία: **«Σχεδιασμός και Υλοποίηση μιας Ολοκληρωμένης Διαδικασίας MLOps για την Πρόβλεψη Stocks σε Πραγματικό Χρόνο»**
Μάριος Μπορόζαν, Τμήμα Μηχανικών Πληροφορικής και Υπολογιστών, Πανεπιστήμιο Δυτικής Αττικής.
Επιβλέπων: Φ. Μυλωνάς.

Το σύστημα προβλέπει την κατεύθυνση (άνοδος / πτώση) της επόμενης ημέρας για μετοχές του S&P 500. Συνδυάζει:

- ένα **Random Forest** εκπαιδευμένο σε 10 χρόνια ημερήσιων δεδομένων όλων των μετοχών του δείκτη (cross-sectional μοντέλο),
- **ανάλυση συναισθήματος** των πιο πρόσφατων τίτλων ειδήσεων με **VADER** και οικονομικό λεξικό.

Ο κύριος στόχος είναι η **υποδομή MLOps**. Περιλαμβάνει αυτόματη ανανέωση δεδομένων, έλεγχο ποιότητας και εκπαίδευση με πλήρη καταγραφή στο MLflow. Τα νέα μοντέλα προωθούνται στην παραγωγή μόνο αν περάσουν μια πύλη αξιολόγησης, και η εξυπηρέτηση των προβλέψεων συνεχίζει χωρίς διακοπή όταν αλλάζει το μοντέλο.

> Δεν αποτελεί επενδυτική συμβουλή. Η αξιολόγηση έδειξε ότι η προβλεπτική ικανότητα του μοντέλου είναι πρακτικά μηδενική (ROC-AUC ≈ 0,50). Δείτε την ενότητα [Αποτελέσματα](#αποτελέσματα).

## Αρχιτεκτονική

Τέσσερα containers με Docker Compose:

| Υπηρεσία | Θύρα | Ρόλος |
|---|---|---|
| `mlflow-server` | 5000 | Tracking Server και Model Registry (SQLite, artifacts) |
| `api` | 8000 | FastAPI: φορτώνει το μοντέλο `@production`, endpoints `/predict`, `/health`, `/reload-model` |
| `frontend` | 8501 | Διεπαφή χρήστη σε Streamlit |
| `pipeline` | – | Αυτόματη ροή με APScheduler |

## Η αυτόματη ροή

`pipeline.py` εκτελεί με τη σειρά:

1. **ingestion**: σταδιακή λήψη μόνο των νέων ημερών (μαζικά αιτήματα ανά 100 μετοχές). Μια πλήρης ανανέωση 10 ετών γίνεται μία φορά την εβδομάδα.
2. **processing**: υπολογισμός χαρακτηριστικών και ένωση όλων των μετοχών σε ένα σύνολο δεδομένων.
3. **validation**: 8 έλεγχοι ποιότητας. Αν αποτύχει κάποιος, η ροή σταματά πριν την εκπαίδευση.
4. **training**: εκπαίδευση με χρονικό διαχωρισμό 80/20, σύγκριση με μοντέλα αναφοράς, βαθμονόμηση, καταχώρηση στο Model Registry.
5. **promotion**: το νέο μοντέλο γίνεται `@production` μόνο αν έχει μεγαλύτερο ROC-AUC από το τρέχον στο **ίδιο** σύνολο ελέγχου και ROC-AUC > 0,50. Μετά την προώθηση το API ειδοποιείται να φορτώσει το νέο μοντέλο.

Χρονοπρογραμματισμός (ώρα Νέας Υόρκης): Δευτέρα–Παρασκευή 17:30 και Σάββατο 06:00 (πλήρης ανανέωση). Κάθε εκτέλεση καταγράφεται στο experiment `SP500_Pipeline_Runs`.

## Χαρακτηριστικά του μοντέλου

Υπολογίζονται στο `features.py`, που χρησιμοποιείται τόσο στην εκπαίδευση όσο και στο API:

| Χαρακτηριστικό | Ορισμός |
|---|---|
| `Daily_Return` | ημερήσια ποσοστιαία απόδοση |
| `Close_vs_SMA10` | Close / SMA10 − 1 |
| `Close_vs_SMA50` | Close / SMA50 − 1 |
| `SMA10_vs_SMA50` | SMA10 / SMA50 − 1 |

Η τελική πρόβλεψη συνδυάζει τις δύο πηγές με άθροιση log-odds:
`logit(p) = logit(p_RF) + NLP_STRENGTH · σκορ_ειδήσεων` (προεπιλογή `NLP_STRENGTH = 1.5`).

## Εκτέλεση

Απαιτείται Docker Desktop.

```bash
docker compose up -d --build
```

- Διεπαφή χρήστη: http://localhost:8501
- API (Swagger): http://localhost:8000/docs
- MLflow: http://localhost:5000

Την πρώτη φορά δεν υπάρχουν δεδομένα ούτε μοντέλο. Μία εκτέλεση της ροής κατεβάζει τα δεδομένα, εκπαιδεύει και προωθεί το πρώτο μοντέλο (διαρκεί αρκετά λεπτά):

```bash
docker compose exec pipeline python pipeline.py --once
```

Logs του χρονοπρογραμματιστή:

```bash
docker compose logs -f pipeline
```

### Τοπικά scripts αξιολόγησης

Με Python 3.12 και `pip install -r requirements.txt`, με τα containers ενεργά:

| Script | Λειτουργία |
|---|---|
| `evaluate_walkforward.py` | αξιολόγηση walk-forward ανά έτος (2021–2026) |
| `collect_headlines.py` | συλλογή τίτλων ειδήσεων για χειροκίνητη επισημείωση |
| `evaluate_sentiment.py` | VADER με και χωρίς οικονομικό λεξικό (Financial PhraseBank + 200 επισημειωμένοι τίτλοι) |
| `benchmark.py` | χρόνος απόκρισης του API (`--rounds`, `--concurrency`) |
| `scan_news.py` | μετοχές με τις πιο θετικές / αρνητικές τρέχουσες ειδήσεις |

Τα γραφήματα αποθηκεύονται στον φάκελο `reports/` και στο MLflow.

## Αποτελέσματα

Σύνολο ελέγχου: 251.019 γραμμές (Οκτ. 2024 – Οκτ. 2026).

| Μοντέλο | Accuracy | ROC-AUC |
|---|---|---|
| Random Forest | 51,07% | 0,5021 |
| Πιο συχνή κλάση (πάντα «άνοδος») | 51,13% | 0,5000 |
| Ορμή («ίδια κατεύθυνση με χθες») | 49,22% | 0,4897 |
| Λογιστική Παλινδρόμηση | 51,13% | 0,5125 |

- **Walk-forward 2021–2026:** μέση ακρίβεια Random Forest 51,46%, μέσο ROC-AUC 0,502. Σε κανένα έτος δεν ξεπερνά ουσιαστικά την πιο συχνή κλάση. Αυτό συμφωνεί με την ασθενή μορφή της Υπόθεσης των Αποτελεσματικών Αγορών.
- **Βαθμονόμηση:** Brier 0,2503 (αναφορά 0,2499), ECE 0,019.
- **Ανάλυση συναισθήματος:** το οικονομικό λεξικό ανέβασε την ακρίβεια του VADER από 57,1% σε 62,6% στο Financial PhraseBank και από 43,0% σε 44,5% στους 200 πραγματικούς τίτλους.
- **Χρόνος απόκρισης:** διάμεσος ~1,5 s ανά πρόβλεψη. Το ~69% του χρόνου πηγαίνει στις ειδήσεις, ενώ το μοντέλο χρειάζεται ~57 ms.

## Δομή

```
├── docker-compose.yml          # οι 4 υπηρεσίες
├── Dockerfile.{mlflow,api,frontend,pipeline}
├── features.py                 # κοινός υπολογισμός χαρακτηριστικών
├── sp500_ingestion.py          # λήψη / σταδιακή ενημέρωση δεδομένων
├── sp500_processing.py         # χαρακτηριστικά και ένωση δεδομένων
├── data_validation.py          # έλεγχοι ποιότητας
├── sp500_training.py           # εκπαίδευση και καταγραφή στο MLflow
├── evaluation_utils.py         # μοντέλα αναφοράς, βαθμονόμηση, γραφήματα
├── promote_model.py            # πύλη προώθησης champion / challenger
├── pipeline.py                 # αυτόματη ροή και χρονοπρογραμματισμός
├── main.py                     # FastAPI
├── sentiment.py                # VADER + οικονομικό λεξικό, ειδήσεις (yfinance / RSS)
├── frontend.py                 # Streamlit
├── evaluate_walkforward.py, evaluate_sentiment.py, benchmark.py,
│   collect_headlines.py, scan_news.py
├── data_sentiment/headlines_to_label.csv   # 200 τίτλοι με χειροκίνητη ετικέτα
└── reports/                    # γραφήματα και αποτελέσματα αξιολόγησης
```

Τα δεδομένα τιμών, η βάση του MLflow και τα μοντέλα δεν περιλαμβάνονται στο αποθετήριο. Δημιουργούνται από την αυτόματη ροή.
